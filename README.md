# Support Ticketing Tool - Full Stack Web Application

A fully functional Support Ticketing Application built with React.js and Node.js REST API.

## 🚀 Live Demo & Repository
- **GitHub Repository:** https://github.com/kavyaarunprasath/ticketing-tool
- **Frontend Deployment:** Deployed via Vercel
- **Backend Deployment:** Deployed via Render

## 🛠️ Tech Stack
- **Frontend:** React.js, HTML5, CSS3, JavaScript (ES6+)
- **Backend:** Node.js, Express.js REST API
- **Version Control & Hosting:** Git, GitHub, Vercel

## ✨ Key Features
- **Ticket Management:** Create, view, update priority/status, and delete tickets.
- **REST API Integration:** Full CRUD operations connected with live endpoints.
- **Responsive Dashboard:** Real-time counters for Total, Open, and Resolved tickets.
- **Search & Filter:** Instant search by ticket title and category.
- **Ticket Details Modal:** Interactive modal popup to view complete issue specifications.
