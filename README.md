# Support Ticketing Tool

A responsive Support Ticketing Tool built with React.js and Node.js.

## Features
- **Dashboard Overview:** Track Total, Open, and Resolved tickets.
- **Ticket Management:** Add new tickets, change status, and delete tickets.
- **Search & Filter:** Search tickets instantly by title.
- **Responsive Design:** Clean and structured UI for desktop and mobile screens.

## Tech Stack
- **Frontend:** React.js, HTML5, CSS3
- **Backend:** Node.js, Express.js
- **Version Control:** Git, GitHub
